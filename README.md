# ContextFlow

เครื่องมือสื่อการเรียนการสอนสำหรับเรื่อง **Token**, **Context Window** และต้นทุนของโมเดลภาษา  
ออกแบบมาให้เดินเรื่องทีละขั้น นักเรียนที่ไม่เคยรู้เรื่อง Token ก็เห็นภาพรวมได้ใน 5–7 นาที

> เวอร์ชันปัจจุบัน: เดิน 9 ขั้น + แผนภาพ Transformer ในโมเดล + ตารางเทียบราคา

## คู่มือครูสั้น ๆ

- ขั้น 5 มีโครงโมเดลย่อ ให้เห็นว่าข้อมูลจะไหลเข้าชั้นไหน
- ขั้น 6 เดินแบบห้องแล็บ: เรื่องเดียวคือทาย Token ถัดไป ใช้ Token จากข้อความผู้เรียน
- เส้นหลัก (residual stream) แบบ Anthropic + โหมดนักเรียน/ครู แบบ Microsoft
- เดินอัตโนมัติ 11 วินาที กดหยุดได้ ไม่วนเมื่อจบ Generation
- กด **หยุดอัตโนมัติ** แล้วยืนอธิบายได้ กดการ์ดหรือ **ขั้นย่อยถัดไป** เพื่อคุมจังหวะห้อง
- แผนภาพเป็นโครง Transformer อย่างย่อ ไม่ใช่โมเดลจริง
- ขั้น 4 เทียบราคาทุกโมเดล มีสูตรคิดของรุ่นที่เลือก และแถวถูกสุดถูกทำเครื่องหมาย
- Overflow ใช้ Model F (4,096) เพื่อให้เห็นส่วนที่ล้น

## แผนที่ทำแล้ว

- Phase 1–2: Overview และกด Next ทีละขั้น
- Phase 3: ตารางเทียบหลายโมเดล Input/Output/รวม
- Phase 4: Animation เส้นทางข้อมูล และแชทจำลอง
- Phase 5: ขยายขั้นในโมเดล + คู่มือครู

## ใช้ในห้องเรียน

1. กด **โหลดตัวอย่าง** หรือพิมพ์ System + User เอง
2. เลือกโมเดลด้านซ้าย สังเกตลิมิตคนละขนาด
3. กด **เริ่มกระบวนการ**
4. กด **Next →** เพื่อเดิน 9 ขั้น: Input → Tokenize → Context → ต้นทุน → ส่งเข้าโมเดล → คิด → ผลลัพธ์ → ขากลับ → แชท
5. กด **ย้อนกลับ** หรือคลิกจุดบนเส้นทางเพื่อทบทวนขั้นที่ผ่านมา
6. อยากสอนเรื่องล้นหน้าต่าง ให้กด **ตัวอย่าง Overflow** แล้วเริ่มกระบวนการ

ลัดคีย์บอร์ด: `Ctrl` / `⌘` + `Enter` เพื่อเริ่ม · ลูกศรซ้าย/ขวา เพื่อย้อน/ถัดไป

## สิ่งที่รองรับแล้ว

- ข้อความ System + User + Multi-turn
- ไฟล์ TXT, DOC, DOCX
- รูปภาพ (คิด Vision Token จากขนาดภาพ ไม่แปลเนื้อหา)
- Tokenizer: `js-tiktoken` (`o200k_base`) พร้อม fallback แบบประมาณค่า
- Overview Mode และ Token Detail แบบ Virtual Scroll
- โหมดกด Next ทีละ 9 ขั้น พร้อม Focus Mode
- Dark Mode เป็นค่าเริ่มต้น
