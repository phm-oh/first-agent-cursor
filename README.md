# ContextFlow

เครื่องมือสื่อการเรียนการสอนสำหรับเรื่อง **Token**, **หน้าต่างบริบท** และต้นทุนของโมเดลภาษา  
ออกแบบมาให้เดินเรื่องทีละขั้น นักเรียนที่ไม่เคยรู้เรื่อง Token ก็เห็นภาพรวมได้ใน 5–7 นาที

> เวอร์ชันปัจจุบัน: เดิน 9 ขั้น + แผนภาพในโมเดล + ตารางเทียบราคา

## คู่มือครูสั้น ๆ

- ขั้น 5 ติดป้ายว่าใครพูด แล้วส่งเข้าโมเดล
- ขั้น 6 สอนเรื่องเดียว: โมเดลทายคำถัดไปทีละคำ จากข้อความของผู้เรียน
- มีเส้นข้อมูลหลักที่ส่งต่อชั้นต่อชั้น และโหมดนักเรียน / ครู
- ตัวเลขในแผนภาพเป็นข้อมูลตัวอย่างประกอบการอธิบาย ไม่ต้องตั้งค่า temperature
- เดินอัตโนมัติ 11 วินาที กดหยุดได้ ไม่วนเมื่อจบทายตัวถัดไป
- กด **หยุดอัตโนมัติ** แล้วยืนอธิบายได้ กดการ์ดหรือ **ขั้นย่อยถัดไป** เพื่อคุมจังหวะห้อง
- แผนภาพเป็นโครงอย่างย่อ ไม่ใช่โมเดลจริง
- ขั้น 4 เทียบราคาทุกโมเดล มีสูตรคิดของรุ่นที่เลือก และแถวถูกสุดถูกทำเครื่องหมาย
- บท **ข้อความยาวจนล้น** ใช้ Model F (4,096) เพื่อให้เห็นส่วนที่ล้น

## แผนที่ทำแล้ว

- ภาพรวม และกดขั้นถัดไปทีละขั้น
- ตารางเทียบหลายโมเดล ข้อความเข้า / คำตอบ / รวม
- ภาพเส้นทางข้อมูล และแชทจำลอง
- ขยายขั้นในโมเดล + บทเรียนห้องเรียน + โหมดนำเสนอเต็มจอ

## ใช้ในห้องเรียน

1. เลือก **บทเรียนห้องเรียน** แล้วกด **โหลดบทเรียนนี้** หรือพิมพ์ข้อความระบบกับข้อความผู้ใช้เอง
2. เลือกโมเดลด้านซ้าย สังเกตความจุคนละขนาด
3. กด **เริ่มกระบวนการ**
4. กด **ขั้นถัดไป →** เพื่อเดิน 9 ขั้น: รับข้อความ → หั่นเป็น Token → หน้าต่างบริบท → คิดราคา → ส่งเข้าโมเดล → ในโมเดล → สร้างคำตอบ → นับคำตอบ → กลับสู่แชท
5. กด **ย้อนกลับ** หรือคลิกจุดบนเส้นทางเพื่อทบทวนขั้นที่ผ่านมา
6. สอนเรื่องล้นหน้าต่าง ให้เลือกบท **ข้อความยาวจนล้น**
7. สอนบนจอโปรเจกเตอร์ กดปุ่มขยายที่หัวเว็บ หรือปุ่ม `P` เพื่อเข้าโหมดนำเสนอ (`Esc` เพื่อออก)

ลัดคีย์บอร์ด: `Ctrl` / `⌘` + `Enter` เพื่อเริ่ม · ลูกศรซ้าย/ขวา เพื่อย้อน/ถัดไป · `P` นำเสนอเต็มจอ

## สิ่งที่รองรับแล้ว

- ข้อความระบบ + ข้อความผู้ใช้ + คุยต่อหลายกล่อง
- ไฟล์ TXT, DOC, DOCX
- รูปภาพ (คิด Token ของรูปจากขนาดภาพ ไม่แปลเนื้อหา)
- Tokenizer: `js-tiktoken` (`o200k_base`) พร้อมตัวสำรองแบบประมาณค่า
- โหมดภาพรวม และดูทีละ Token
- โหมดกดขั้นถัดไปทีละ 9 ขั้น
- บทเรียนห้องเรียน 6 ชุด และโหมดนำเสนอเต็มจอ
- โหมดมืดเป็นค่าเริ่มต้น
