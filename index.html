Teaching note

Token ไม่ใช่คำ และไม่ใช่ตัวอักษรเสมอไป ภาษาไทยมักใช้ Token มากกว่าภาษาอังกฤษในความยาวเท่ากัน

Context

Context Window คือความจุสูงสุดที่โมเดลอ่านได้ในหนึ่งรอบ หากล้น ข้อมูลส่วนท้ายอาจไม่ถูกใช้

Why it matters

จำนวน Token กำหนดทั้งความเข้าใจของโมเดล และราคาต่อครั้ง จึงควรเห็นภาพก่อนส่งงานจริง

Educational caption

พิมพ์ข้อความด้านซ้าย แล้วสังเกต Context Window ด้านขวาว่า Token ถูกใช้ไปเท่าไร
